# ⚡ Smart-ESC 18-Mosfet: High-Power Open-Source EV Controller

A high-performance, intelligent, open-source 3-phase BLDC/FOC motor controller designed for electric vehicles. This project integrates automotive-grade power routing with advanced microcontroller logic, engineered completely from scratch under extreme budget constraints using salvaged components.

---

## 🚀 Key Hardware Specifications & "Dị" Features

Unlike standard controllers, this board implements advanced power-stage and signal-integrity techniques to handle massive currents without signal distortion:

*   **18-Mosfet Power Stage:** Features 3 parallel Mosfets per half-bridge leg to distribute high phase currents uniformly. 
*   **Heavy Busbar Ready (Expose Copper Layers):** Hand-routed exposed copper tracks on Top/Bottom layers (2oz thickness) specifically designed to be reinforced with external thick copper busbars for maximum heat dissipation and current-carrying capacity.
*   **3D Shielded Gate Routing (Inner Layer 3):** To prevent destructive EMI generated by the heavy busbars from corrupting the gate signals, all 18 gate drive traces are hidden inside **Inner Layer 3**, fully sandwiched and shielded by solid GND planes on adjacent layers.
*   **3-Stage Robust Power Supply:** A custom step-down cascading topology (**72V → 12V → 5V → 3.3V**) designed to drop high battery voltage down safely to feed the gate drivers (12V) and the sensitive digital circuits (5V/3.3V) without blowing the ICs.
*   **Brainpower:** Driven by the powerful **STM32F405RGT6** ARM Cortex-M4 MCU running at 168MHz with a hardware Floating Point Unit (FPU).

---

## 🛠️ Smart Features (Firmware Under Development)

The custom C firmware (Register-level optimization) is being coded to support full vehicle integration:
*   **Regenerative Braking:** Energy recovery to recharge the 72V battery pack during braking.
*   **Anti-Theft System:** Active wheel locking and buzzer alarm triggered by hardware interrupts if unauthorized movement is detected.
*   **Bluetooth Connectivity:** Smartphone telemetry for real-time speed monitoring, diagnostics, and eco/sport mode switching.
*   **Fail-Safe Protections:** Hardware-level overcurrent shutdown utilizing the STM32 `TIMx_BKIN` (Break Input) pin to lock all PWM outputs within nanoseconds during a short-circuit.

---

## 📐 Board Layer Stackup (4-Layer PCB)
*   **Top Layer:** 0.070mm (2oz) - Power & Busbar path
*   **Inner Layer 1:** 0.020mm - Ground Plane
*   **Inner Layer 2 / 3:** 0.020mm - Shielded Signal Routing (Gate Drive)
*   **Bottom Layer:** 0.070mm (2oz) - Power & Ground return path

## 🧑‍💻 About the Author & The "Zero-Budget" Journey
I am a 14-year-old self-taught hardware and nhúng (firmware) developer. Electronics is my home and my passion. Because I operate on a zero-budget, this entire project is built by harvesting SMD and through-hole components from discarded electronic scrap. 

Due to a lack of professional equipment, my tools consist of a cheap $2 soldering iron hand-filed into a knife-tip shape, and a homemade capacitor meter built from an old computer sound card. I routinely dedicate 10 to 12 hours a day to mastering hardware logic and C programming. 

> *"Academic grades don't define capability. Relentless curiosity, pure logic, and execution do."*
